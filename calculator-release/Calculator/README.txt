Calculator App for RG34xxsp
============================

Installation Instructions:

1. Copy this entire "Calculator" folder to your RG34xxsp SD card at:
   /Roms/APPS/Calculator/

2. The folder should contain:
   - calculator (the app executable)
   - calculator.sh (launch script)
   - README.txt (this file)

3. Eject the SD card safely and insert it back into your RG34xxsp

4. Power on the device and navigate to APPS menu

5. Select "Calculator" to launch the app!

Controls:
---------
D-Pad: Navigate between calculator buttons
A Button: Press the selected button
Menu/Select: Exit calculator

Features:
---------
- Basic arithmetic: +, -, *, /
- Decimal point support
- Clear (C) and All Clear (AC)
- Delete last digit (DEL)
- 16-digit precision
- Error handling

Enjoy calculating!
